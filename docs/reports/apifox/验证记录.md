## 集合内置自动化（导入即生效）

1. **Idempotency-Key**：集合级前置脚本自动生成随机值（`apifox-` + 时间戳36进制 + 随机串，≥8 字符）；
2. **HMAC 签名**：登录态写请求自动补 `X-Timestamp / X-Nonce / X-Signature`；
   - 签名原文 = `POST\n{路径}\n{ISO时间戳}\n{随机数}\n{sha256(body)}`
   - 密钥 = 当前 access token
   - 与 `backend/src/api/core.ts` 的 `createHmac('sha256', token)` 校验逐字节一致（实测 201 证明）
3. **环境变量**：登录自动写 `token`；秒杀自动写 `reqId`；`baseUrl` 默认 `http://127.0.0.1:3001`。

## 备注

- `POST /v1/plans` 会真调 DeepSeek 生成行程，响应 7s+ 属正常，Apifox 超时建议设 ≥30s；
- 秒杀前置条件：Redis 有库存 key（`docker exec redis redis-cli set "stock:1:2026-12-01" 10 EX 86400`），否则一律 sold_out；
