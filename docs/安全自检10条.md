# 安全自检 10 条（组员6 · 验收裁判官）

> 对应吴老师要求："防内盗、防外盗"，鉴权必须用现成框架（Spring Security / Shiro / Sa-Token / FastAPI 依赖注入），不许裸写鉴权。

## 一、认证安全

- [ ] **1. 未带 Token 访问受保护接口 → 401**（Pytest 用例 `test_no_token_access_me_returns_401` 通过）。
- [ ] **2. 伪造/过期 Token → 401**（`test_invalid_token_returns_401` 通过）。
- [ ] **3. 密码加密存储**：数据库里密码必须是 bcrypt/argon2 哈希，**不得明文**。
- [ ] **4. 密码错误 5 次锁定**（`test_wrong_password_5_times_locks_account` 通过），防暴力破解。

## 二、授权安全（防越权）

- [ ] **5. 普通用户访问 `/admin/*` → 403**（`test_normal_user_cannot_access_admin_returns_403` 通过，防水平/垂直越权）。
- [ ] **6. 权限资源只控到菜单+按钮级**：按吴老师要求，不做数据级权限，但菜单/按钮必须按角色隔离。
- [ ] **7. 退出即撤销 Token**：调用 `/auth/logout` 后该 token 立即失效（加入黑名单/Redis 注销）。

## 三、防刷与防护

- [ ] **8. 登录接口限流**：同一手机号/IP 高频请求返回 429（`test_login_rate_limit_returns_429` 通过），JMeter 压测报告确认限流生效。
- [ ] **9. 敏感字段脱敏**：手机号等返回时脱敏（如 `138****1234`），日志中不打印完整手机号/密码/token。
- [ ] **10. 写操作幂等**：POST/PUT 接口校验 `Idempotency-Key`，重复请求不产生副作用。
