# Node 内部接口契约（S1）

只供可信 Java 服务调用。浏览器不持有内部密钥，Node 也不信任 `X-Forwarded-For`。

## 请求认证

所有请求使用 HTTPS（生产）或受限的内部网络（本地开发），并携带：

| Header | 格式 |
|---|---|
| `X-Timestamp` | Unix epoch 毫秒，允许与服务器时间相差最多 5 分钟 |
| `X-Nonce` | 16–128 位 `[A-Za-z0-9-]` 随机串，Redis 去重 5 分钟 |
| `X-Internal-Key` | 以 `INTERNAL_API_SECRET` 为密钥计算的 HMAC-SHA256 小写十六进制摘要 |

签名原文为以下五行（LF 分隔、末尾无换行）：

```text
HTTP_METHOD
/internal/完整路径
X-Timestamp
X-Nonce
SHA256(JSON.stringify(请求体或空对象))
```

使用 `INTERNAL_API_SECRET`（至少 32 字符），不得复用用户 JWT、数据库密码或其他业务密钥。服务端先检查 socket 对端为回环/RFC1918/ULA 地址，且命中必填的 `INTERNAL_ALLOWED_IPS` 精确 IP 白名单，再验证 HMAC 和时间戳，最后用 Redis `SET NX EX` 消费 nonce。开发环境可设为 `127.0.0.1,::1`；生产应配置 Java 出口 IP。Redis 不可用时拒绝请求（503），不降级为无重放保护。

外层 Nginx 不代理 `/internal/*`；其静态兜底对该路径返回 404。Node 直接收到公网来源时返回空 404；私网来源但签名错误、过期或重放返回 401。

## 定时任务

| 方法与路径 | 幂等效果 |
|---|---|
| `POST /internal/timers/expire-orders` | 事务锁定并取消到期订单、释放库存；重复执行不重复释放 |
| `POST /internal/timers/refresh-stock` | 仅创建 Redis 中缺失的库存 key，不覆盖进行中的预扣 |
| `POST /internal/timers/seckill-toggle` | 按活动起止时间覆盖写 `seckill_enabled` |
| `POST /internal/timers/dashboard-preagg` | 覆盖写 Redis `dashboard:preagg`（TTL 2 小时） |

同一任务同一分钟重复调用会复用首个结果；并发执行返回 409。执行锁按任务隔离，失败只影响当前任务。Node 不启动这四类周期调度，Java `@Scheduled` 负责触发并记录任务耗时/结果。
