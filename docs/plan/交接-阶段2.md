## 三、接口清单

### `POST /v1/seckill/:routeId`
- 需要登录（`Authorization: Bearer <token>`）
- Body: `{"date":"2026-12-01","people":1}`
- 成功：`202 Accepted {"data":{"status":"queued","req_id":"uuid"}}`
- 售罄：`200 {"data":{"status":"sold_out"}}`
- Redis不可用：`503`

### `GET /v1/seckill/result/:reqId`
- 需要登录
- 返回：`{"data":{"status":"pending|success|failed","order_id":123}}`
- 前端轮询：1s一次，最多10次

## 四、Redis Key 清单

| Key | 类型 | TTL | 说明 |
|---|---|---|---|
| `stock:{routeId}:{date}` | String(数字) | 活动日期+1天 | Lua脚本扣减的库存 |
| `seckill:stream` | Stream | 无 | 秒杀消息队列 |
| `seckill:stream:dlq` | Stream | 无 | 死信队列 |
| `seckill:result:{reqId}` | String(JSON) | 600s | 抢购结果，前端轮询 |

> 所有 key 自动加 `REDIS_KEY_PREFIX` 前缀（.env 里配的 `z3_`）。

## 六、踩过的坑（重要）

1. **消费者必须用独立 Redis 连接**：`XREADGROUP BLOCK 2000` 会阻塞连接2秒，如果和业务共用同一个 ioredis 连接，所有 HTTP 请求都会超时。consumer.ts 里已经 `createConsumerRedis()` 独立连接，不要改回去。
2. **MariaDB 不支持 `utf8mb4_0900_ai_ci`**：项目原SQL是MySQL8.0排序规则，MariaDB要改成 `utf8mb4_general_ci`。
3. **预热时机**：`warmUpAllSeckillStock()` 在 Redis 连上之前执行会失败，启动后需手动预热或等Redis ready后重试。
4. **MQ 是 Redis Stream 不是 RabbitMQ**：不要装 RabbitMQ，直接用 ioredis 的 XADD/XREADGROUP/XACK。
