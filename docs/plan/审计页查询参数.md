# 审计页查询参数（T7 Node 数据半边）

`GET /v1/admin/audit/logs` 需 `system:permission:query` 权限。

| 参数 | 说明 |
|---|---|
| `type` | 必填：`login`、`operation` 或 `system` |
| `level` | 系统日志级别过滤：`trace/debug/info/warn/error/fatal` |
| `from` / `to` | ISO-8601 含时区的时间边界；`from` 不可晚于 `to` |
| `page` / `size` | 页码 1–100；每页 1–100 条，默认 1 / 20 |

登录和操作日志来自 `sys_login_log` / `sys_operation_log`；系统日志从 Node pino JSON 文件读取最近 5000 行后过滤。业务日志只保存脱敏账号、状态码、路径和操作元数据，不落请求体。`sys_audit_log` 额外保存权限变更审计，含 `client_ip`、`ua`、`result`。
