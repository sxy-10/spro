## 3. 启动与配置

1. Node 侧 `.env`：`INTERNAL_API_SECRET=<≥32 字符>`、`INTERNAL_ALLOWED_IPS=127.0.0.1,::1`（部署机私网 IP）。
2. Java 侧环境变量（或 `application.yml`）：`INTERNAL_API_SECRET` 必须与 Node 完全一致。
3. `cd java-web && ./mvnw spring-boot:run -Dskip.frontend=true`（前端已构建过 jar 时直接用 `java -jar`）。
4. 自检：`GET /api/internal/timers` 应看到四个任务的最近一次耗时与结果；
   任一任务 `ok=false` 时先看 `X-Internal-Key` 与出口 IP 白名单。

### 演示时要注意的两点（踩过）

1. **同一分钟内重复点「立即预聚合」不会重算**：Node 的 `POST /internal/timers/:task` 按"分钟桶"缓存结果（`internal:timer:result:*`，10 分钟 TTL），
   同一分钟内第二次调用直接返回上一次的结果。验收"恢复后更新"时，若刚触发过就再触发，会看到旧的 `generated_at` —— 属既有设计（防重复计算），
   等下一秒/下一分钟桶再触发即可，不是缺陷。
2. **`seedGuidesTeams.ts` 在全新库上会报外键错**（`fk_member_order`），见 `docs/plan/Node问题单.md` #5，本判据不受影响。
