# 交接 · S3 平台方与日志审计（组员2 → S4/验收）

> 完成日期：2026-11-27。本文档是 S3 的交接入口；实施过程与每行代码解释见同目录《组员2-S3实施教程.md》。

## 1. 审计页查询参数（J3 冻结物的使用说明）

- 统一走 `GET /api/platform/logs`；`type` 必填三选一（`login` / `operation` / `system`）；
  `level` 仅 `system` 有效（其他类型传了直接 400）；`from/to` 必须 ISO-8601 **带时区**
  （前端 `dayjs.toISOString()` 直接满足，裸 `2026-11-26T08:00:00` 会被 zod 拒掉）；`page/size` 各 1–100。
- 分页/时间格式与 S4 大屏轮询共用同一口径（`api/core.ts` 的 `page()` + `list()`）。
- **时间口径**：`sys_login_log` / `sys_operation_log` 的 `created_at` 是 **UTC 墙钟**
  （`backend/src/db/connection.ts` 的 mysql2 配 `timezone:'Z'`），API 返回 `2026-11-27T02:08:45.747Z` 形态；
  展示层由前端 `fmtTime` 转本机时区。**筛选取本地时间、内部自动转 UTC**——表格看到几点就按几点筛。
- 系统日志（`type=system`）**不落库**，读 pino 文件尾部 5000 行（`nodeLogPath`），无分页总数、`has_more` 判断是否还有。

## 3. /api/platform/* 接口清单

（与 `docs/specs/API_V1.md` 末尾「平台方 BFF 聚合接口」节一致）

| 方法 | 路径 | Node 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/platform/logs` | system:permission:query | 日志三页统一入口；query：type(必填)、level(仅 system)、from/to(ISO-8601 含时区)、page、size；返回 {list,total,has_more} |
| GET | `/api/platform/permissions` | system:permission:query | 权限树 + 按钮清单（角色页数据源） |
| GET | `/api/platform/roles/{id}/permissions` | system:role:query | 角色已授权 permission_id 列表 |
| PUT | `/api/platform/roles/{id}/permissions` | system:role:update | 全量覆盖授权；body: **{permission_ids:[...]}**（snake_case）；Node 自动补祖先菜单 |
| GET | `/api/platform/overview` 等其余 9 页聚合接口 | 见各页 | 与 PlatformController 一一对应，字段透传 snake_case |

写接口需 CSRF 头 `X-XSRF-TOKEN`（`lib/http.ts` 自动带）；幂等键与 HMAC 签名由 BFF 服务端补齐，**浏览器不接触任何令牌**。

### 对 S1/S2 Java 侧的追加（跨组，均已登记 `docs/plan/Node问题单.md`）

- **#2 `NodeApiClient.java`（S2 建的文件）**：转发改为 `URI.create(baseUrl + path)` 自拼绝对地址。
  原因：`uri(String)` 会二次编码 `%XX`（时间参数 → 10001）；`uri(相对URI)` 不套 baseUrl（→ `URI with undefined scheme` 500，验证码/登录全挂）。含回归单测。
- **全局 Jackson 是 SNAKE_CASE**：前端写请求体必须发 `permission_ids`（发驼峰 `permissionIds` 会静默变 null → 10001）。
- 已知既有测试红灯：`AuthFlowTest` 4 例（组员4 IM 域的 `ImWebSocketConfig` 在 MockMvc 下无 `ServerContainer`），见问题单 #3；`NodeApiClientTest` 5/5 绿。
