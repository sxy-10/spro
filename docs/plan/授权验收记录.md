# 授权验收记录（阶段 3）

## 权限迁移

执行：

```bash
mysql -u root -p < database/05_rbac_schema.sql
mysql -u root -p < database/08_rbac_complete.sql
mysql -u root -p < database/10_audit_log.sql
```

## 验收项

- 游客访问管理线路：`403/20013`
- 游客读取行程：`200`
- 游客创建行程：`200/201`
- 游客创建普通订单：`200/201`
- 游客查询订单：`200`
- 游客发表评论：`200/201`
- 游客秒杀下单：持有 `order:seckill` 时可进入秒杀守卫
- 游客可查询和发送智能体会话；缺少会话归属时返回 `404`

## 即时通讯补充验收

- 游客持有 `im:*` 权限可创建会话、发送消息、查询消息和已读游标。
- 非参与者访问会话：`404/20016`
- 重复 `client_msg_id`：同一用户只落一条消息。
- 断线后使用 `since_seq` 拉取可补齐漏发消息。
- 修改其他用户资料：非本人且无 `system:user:update` 时 `403/20013`
- 健康检查：`GET /v1/health` 返回 `{ "status": "ok" }`

## 权限码

游客最小业务权限：

- `itinerary:plan:query`
- `itinerary:plan:add`
- `itinerary:plan:update`
- `itinerary:plan:export`
- `route:line:query`
- `order:add`
- `order:query`
- `comment:add`
- `order:seckill`
