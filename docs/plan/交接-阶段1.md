## 使用示例

```text
POST /v1/im/conversations
POST /v1/im/messages
GET  /v1/im/conversations/:id/messages?since_id=0
POST /v1/im/messages/:id/read
GET  /v1/im/conversations/:id/unread
GET  /v1/stats/live
```

发送消息要求 `Authorization: Bearer <token>`，并持有对应 `im:*` 权限。会话、成员、消息、已读游标、未读数与实时统计已落地；写接口使用幂等键、请求签名和数据库事务。真实跨设备推送、离线补偿和 MQ 通知可由后续阶段接入现有序列号与游标模型。
