## 使用示例

```text
POST /v1/im/conversations
POST /v1/im/messages
GET  /v1/im/conversations/:id/messages?since_id=0
POST /v1/im/messages/:id/read
GET  /v1/im/conversations/:id/unread
GET  /v1/stats/live
```

发送消息要求 `Authorization: Bearer <token>`，并持有对应 `im:*` 权限。除历史消息 SQL 查询外，接口目前按约定返回 501 占位；真实 WS、序列号、离线补偿和 MQ 通知由后续阶段实现。
