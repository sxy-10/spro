# 定时任务清单（T4 Node 半边）

Node 只提供有签名的任务执行入口，不自行调度。Java 侧分别配置调度并记录任务名、耗时、结果和告警。

| 名称 | 建议频率 | Node 路径 | 幂等键 / 收口方式 | 失败处理 |
|---|---|---|---|---|
| `expire-orders` | 每 10 秒 | `POST /internal/timers/expire-orders` | 事务 + `FOR UPDATE SKIP LOCKED`；仅取消仍为 PENDING 的到期订单 | Java 记录失败并告警，下个周期重试 |
| `refresh-stock` | 每 5 分钟 | `POST /internal/timers/refresh-stock` | Redis `SET NX` 只补缺失 key，不覆盖在途扣减 | Redis/MySQL 错误返回失败，下个周期重试 |
| `seckill-toggle` | 每 1 分钟 | `POST /internal/timers/seckill-toggle` | 条件计算并覆盖 `seckill_enabled` | SQL 错误返回失败，不影响其他任务 |
| `dashboard-preagg` | 每 5 分钟 | `POST /internal/timers/dashboard-preagg` | Redis key `dashboard:preagg` 覆盖写，TTL 2 小时 | SQL/Redis 错误返回失败，不影响其他任务 |

每个任务按名称和当前分钟建立独立执行锁与 10 分钟结果缓存；同分钟重放返回相同结果，执行中的并发请求返回 409。库存预热只补空 key，绝不能在 Kafka 尚有 lag 时用 MySQL 重置正在处理的秒杀库存。
